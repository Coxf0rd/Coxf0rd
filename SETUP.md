# Coxf0rd GitHub profile — установка

Это готовый GitHub Profile README. В нём используется стиль Tech / Dark Blue с оригинальными локальными SVG-элементами.

## Установка через браузер

1. Откройте репозиторий https://github.com/Coxf0rd/Coxf0rd . Это профильный репозиторий, НЕ FWRouter.
2. При необходимости сохраните копию прежних `README.md`, `README_EN.md` и папки `assets`.
3. Замените файлы `README.md` и `README_EN.md`, затем загрузите все файлы папки `assets` **с сохранением путей**.
4. Убедитесь, что `assets/header.svg`, `assets/terminal.svg`, `assets/tech-stack.svg` и другие SVG отображаются в README.
5. Сделайте commit в ветку `main` профильного репозитория.
6. Откройте https://github.com/Coxf0rd и проверьте профиль.

Важно: стандартный фон интерфейса GitHub, левую колонку с аватаром, встроенные счётчики, кнопки и панели заменить через README нельзя. Здесь оформляется только область, отведённая GitHub под профильный README. Цифры звёзд/репозиториев и публичность PetriNet намеренно не выдуманы.

## Дополнительное оформление

- В настройках GitHub-профиля можно отдельно указать имя и краткое Bio.
- `Customize your pins` позволяет закрепить FWRouter на основной странице.
- Скриншот интерфейса и архитектуру FWRouter можно добавить позже.
- README содержат заранее оставленные комментарии под архитектурную схему, которые сейчас не отображаются.
