# Installation

Copy **the contents of this folder** into the root of the public GitHub repository `Coxf0rd/Coxf0rd`, replacing the existing `README.md`, `README_EN.md` and uploading all files under `assets/`.

This edition uses one single, detailed SVG per language, with uniform background. GitHub site chrome and user sidebar are not customizable.

The navigation labels and FWRouter hyperlink remain live outside the SVG; embedded text in the SVG itself is a graphic and not selectable/clickable.
